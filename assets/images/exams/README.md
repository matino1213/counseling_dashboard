# تصویر کارت‌های «آزمون‌های من»

پنج فایل زیر از خودِ طرح نمونه برش می‌خورند؛ نام هر آزمون بخشی از همین
تصویرهاست و در کد به‌صورت متن نوشته نمی‌شود:

| فایل | محتوا |
| --- | --- |
| `neo.png` | تصویر کارت آزمون NEO |
| `cattell.png` | تصویر کارت آزمون کتل |
| `mbti.png` | تصویر کارت آزمون MBTI |
| `shakle.png` | تصویر کارت آزمون شاکله |
| `cattell_wide.png` | تصویر بنر «ادامه آزمون» |

تولیدشان با اسکریپت مخزن (مستطیل‌ها پیکسل‌به‌پیکسل از عکس اندازه‌گیری شده‌اند):

```bash
python tool/crop_exam_art.py "C:/path/to/mock.png"
```

تا وقتی این فایل‌ها ساخته نشوند، کارت‌ها به گرادیان نمونه‌برداری‌شده از همان
طرح برمی‌گردند (`ExamArt` یک `errorBuilder` دارد) و صفحه نمی‌شکند.
